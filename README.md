# gakutenchoon

iPhone・iPad 向けアプリ「楽典・聴音ドリル」(開発・運営: Takaho Hayashi)のサポート・プライバシーポリシー・利用規約のページです。GitHub Pages(`main` ブランチの `/docs`)で公開します。

- サポート: https://taaaaho.github.io/gakutenchoon/
- プライバシーポリシー: https://taaaaho.github.io/gakutenchoon/privacy.html
- 利用規約: https://taaaaho.github.io/gakutenchoon/terms.html

App Store で公開したら、`docs/index.html` の `APP_STORE_LINK` の箇所をアプリのページへのリンクに置き換え、ルートの taaaaho.github.io の一覧にも追加してください。
