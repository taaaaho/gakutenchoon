iPhone・iPad 向け学習アプリ

楽典・聴音ドリル

開発・運営: Takaho Hayashi(個人開発)
App Store: 公開準備中

音大・音楽高校の受験などで学ぶ「楽典」と「聴音」を、毎日くり返し練習するためのアプリです。 楽典は音名・音程・音階・調と調号・近親調・和音・終止形・移調と移調楽器・拍子とリズム・音楽用語・装飾音と反復記号の10章。 音程・調・和音などの計算問題は解くたびに新しい問題を自動で作ります。 聴音はアプリ内のピアノ音源で、音程・和音・音階・短い旋律を選択式で聞き分けます。 楽典20問と聴音10問の総合テスト(このアプリ独自の構成)もあります。

問題と解説はすべて開発者が作成したオリジナルで、特定の学校の入試問題や市販教材の文章は掲載していません。入試の形式・出題範囲は学校によって異なります。 聴音は選択式の聞き分けで、五線への書き取りや新曲視唱(歌唱の判定)には対応していません。

よくあるご質問

  • 音が出ない
    本体の音量を上げてください(音量が0のときはアプリの画面に注意が出ます)。本アプリはマナーモードでも音が鳴ります。イヤホン・AirPods を接続・切断したときも、そのまま続けて再生できます。
  • 購入した「全機能解除」が反映されない
    「設定」タブの「購入を復元」をお試しください。同じ Apple ID でサインインしている端末で復元できます。改善しない場合は上記のメールアドレスまでご連絡ください。
  • 基準ピッチや音名の表記を変えたい
    「設定」タブで、基準ピッチ(A=442Hz / 440Hz)、鍵盤の音名(日本音名・ドイツ音名・英語音名・ドレミ)、移動ドの表示、聴音の音域を変更できます。
  • 問題や解説に誤りを見つけた
    章の名前と問題文を添えて、上記のメールアドレスまでお知らせください。確認のうえ修正します。
  • 学習の記録はどこに保存されますか
    お使いの端末の中だけに保存します。アカウント登録やログインはなく、記録を外部へ送信することもありません。
